# Architecture Decision Records

Numbers 0054 to 0057, 0059 to 0062, 0064 to 0067, 0077, 0083, 0087, 0089 to 0092, 0097, and 0098 are unused. No ADR uses them, and no number is renumbered, so existing links hold.

- 0001 — [Hybrid orchestrator with deterministic runtime](0001-hybrid-orchestrator-runtime.md) — superseded — Replaces the fixed worker-first review loop with an LLM orchestrator that selects actions executed by a deterministic runtime. Superseded by ADR 0019, which restates it.
- 0002 — [Harness-neutral orchestrator instructions with thin entry points](0002-harness-neutral-orchestrator-instructions.md) — accepted — One instruction file defines the interactive orchestrator role and thin harness entry points.
- 0003 — [GitHub Copilot CLI session entry point and parent guard](0003-copilot-session-entrypoint-and-parent-guard.md) — superseded — The Copilot launcher and repository hook pass and enforce the parent session id. Superseded by ADR 0005.
- 0004 — [Distribute the CLI as a scoped public npm package](0004-scoped-npm-distribution.md) — superseded — Publish `@andromarces/agent-loops` with a provenance release workflow and a portable prepare guard. Superseded by ADR 0022, which restates it.
- 0005 — [User-scope harness integrations only](0005-user-scope-integrations.md) — accepted — `agent-loop install` sets up every entry point and guard at user scope; after #139, no agent-loop integration stays at workspace level.
- 0006 — [Require a parent session id for interactive runs](0006-require-parent-session-for-interactive-runs.md) — accepted — Every `agent-loop role` init requires `--parent-session` and rejects an unexpanded placeholder; the headless command is the explicit unguarded path.
- 0007 — [Concurrent role runs from one parent session](0007-concurrent-session-runs.md) — accepted — Init registers one session entry per run keyed by work tree; the guard denies while any entry is non-terminal and the reader unions the legacy single-path index.
- 0008 — [Keep the turn history in the state file](0008-state-file-turn-history.md) — partially-superseded — Every dispatch appends one fixed-shape `turns` entry (role, status, verdict, head, at) to the state file. Partially superseded by ADR 0084: a refunded first-turn model refusal records an entry without a charge, so the array holds at most `maxSteps` entries plus one refunded refusal for each role.
- 0009 — [Declare a PR input on every run that is PR work](0009-declare-a-pr-input-on-every-run.md) — partially-superseded — `--pr <pr>` declares the run PR work on both paths, so that run must end through the `--require-ci <pr>` gate for the same PR and cannot record `unresolvedCompare`. The no-required-check ceiling its Consequences recorded is lifted by ADR 0012. Partially superseded by ADR 0041: `--pr` can also be set once after init.
- 0010 — [A runtime-owned bound on the interactive required-check wait](0010-runtime-owned-required-check-wait-bound.md) — partially-superseded — `agent-loop role wait-checks` polls the required checks inside a stated bound and returns their states with a `timedOut` flag, because a shell `timeout` does not exist on both supported platforms. Partially superseded by ADR 0048: the envelope names the `head` that its checks describe and the states are read by commit SHA.
- 0011 — [Supply the required-check status to the reviewer from the runtime](0011-supply-the-required-check-status-to-the-reviewer.md) — superseded — A declared-PR run reads the required-check status before each reviewer turn and supplies it in the prompt; the reviewer's own read stays the fallback.
- 0012 — [Establish an absent required check from an allowlisted source reply](0012-establish-the-absence-of-a-required-check.md) — accepted — Each required-check source is classified absent, contexts, or unknown by an allowlist, so only one exact reply per source proves an absence; every other reply, and a merge state the gate cannot read, keeps the refusal.
- 0013 — [Bound the headless required-check wait with the runtime wait](0013-bound-the-headless-required-check-wait.md) — partially-superseded — The headless orchestrator runs `role wait-checks` with a `--timeout` derived from the turn `--timeout`, and reads `timedOut: true` as a pending check, not a pass.
- 0014 — [Extend the step budget of a live interactive run](0014-extend-the-step-budget-of-a-live-run.md) — partially-superseded — `agent-loop role extend --parent-session <id> --max-steps N` raises `maxSteps` in place on a non-terminal run, keeping role sessions, and records each change in `budgetChanges`. Partially superseded by ADR 0084: a refunded first-turn model refusal records an entry without a charge, so the array holds at most `maxSteps` entries plus one refunded refusal for each role. Partially superseded by ADR 0106: the budget of a batch loop spans attempts and a continued attempt spends the remainder, so the fixed `--max-steps` of one headless invocation is a slice of one loop budget.
- 0015 — [Continue a headless run from its transcript](0015-continue-a-headless-run-from-its-transcript.md) — superseded — `--continue-from <transcript>` resumed the earlier role sessions with a new budget and reset the gate state. Superseded by ADR 0023, which restores the gate state on an unchanged work tree.
- 0016 — [Resume the session of a failed first turn, with a fallback to a new session](0016-resume-a-failed-first-turn-with-a-fallback.md) — superseded — A failed first turn keeps the session id its output printed, and a Claude first turn pre-assigns its id; a resume the CLI reports as missing clears the id and reruns the turn once as a first turn inside the same step. Superseded by ADR 0027.
- 0017 — [Run an operator test command before each reviewer turn](0017-run-a-test-command-before-each-reviewer-turn.md) — partially-superseded — `--test-cmd` runs in the runtime before each reviewer turn, bounded and killed through its own process group or tree (an orphan that left it can survive), and supplies the exit code and an output tail as advisory untrusted evidence, with work tree changes reported; secret-named environment values are redacted from the tail, the command text, and every error text and log line.
- 0018 — [Copy untracked local files into a linked run work tree](0018-copy-local-files-into-a-linked-run-work-tree.md) — partially-superseded — At init, a linked `--cwd` receives each untracked file of the main work tree that `--cwd` ignores, without overwrite, symlink, work tree, or content in any output; `--no-copy-local-files` opts out.
- 0019 — [Opt in to a workspace-write sandbox for the Codex reviewer](0019-opt-in-workspace-write-sandbox-for-the-codex-reviewer.md) — partially-superseded — `--reviewer-workspace-write` runs a Codex reviewer turn in `workspace-write` with shell network off, keeps the orchestrator read-only and the mutation check on, and records five accepted gaps, since enforcement for that turn becomes detective. Supersedes ADR 0001 and restates its live decisions. Partially superseded by ADR 0038.
- 0020 — [Remove orphan claim files with a writer liveness check](0020-remove-orphan-claim-files-with-a-writer-liveness-check.md) — accepted — Each lock acquisition removes claim files whose pid is dead or whose unwritten file has no live marker and is past a grace window; a per-process-token marker in the creator's temp name protects a running writer at any age.
- 0021 — [Do not let a new session take over a run](0021-no-parent-session-takeover.md) — accepted — No takeover command: no check stops a child that read the stored id from releasing the guard. A resumed run from another session stays unguarded; abort and re-init to guard it.
- 0022 — [Run the dev toolchain and Git hooks through Vite+](0022-vite-plus-toolchain-and-npm-distribution.md) — accepted — `vite-plus` replaces `oxfmt`, `oxlint`, `vitest`, `lint-staged`, and `husky`; the `prepare` guard installs the Vite+ hook dispatcher, hooks keep format-only `pre-commit` and the `pre-push` gate, and `engines.node` follows the `vite-plus` range. Each `vite-plus` upgrade re-pins the `vitest` override. Supersedes ADR 0004 and restates its live decisions.
- 0023 — [Restore the headless gate state on a continued run](0023-restore-the-headless-gate-state-on-a-continued-run.md) — superseded — `--continue-from` derives the gate state from the earlier result events, validates it strictly, and restores it only when the current work tree has the head and digest of the last reviewed state. Supersedes ADR 0015. Superseded by ADR 0026.
- 0024 — [Supply the required-check status to the reviewer for every run that names a PR](0024-supply-the-required-check-status-for-a-named-pr.md) — accepted — Supersedes ADR 0011 and narrows ADR 0013 decision 6. A run that names a PR with `--pr`, or a headless `--require-ci <pr>`, reads the required-check status before each reviewer turn and supplies it in the prompt; the reviewer's own read stays the fallback.
- 0025 — [Lock the install manifest beside the install home](0025-lock-the-install-manifest-beside-the-home.md) — accepted — `install` and `uninstall` lock `<home>/.agent-loops.lock`, keyed by location, so processes with different `TMPDIR`/`TEMP` contend on one lock; reverses the #193 preference to keep the home free of lock files.
- 0026 — [Detect a changed resolved model on --continue-from](0026-detect-a-changed-resolved-model-on-continue-from.md) — accepted — Supersedes ADR 0023. Claude (the `init` event model), Copilot, and opencode (`session export`) report the resolved model, which the transcript records per role. `--continue-from` probes it once per recorded role, under the mutation check and SIGINT cancel of a child turn, and refuses a change. Codex and agy report none in a supported output and stay unchecked; a record with no model warns that the check did not run.
- 0027 — [Save the session id of an in-tree transcript outside the work tree](0027-save-the-session-id-of-an-in-tree-transcript-outside-the-work-tree.md) — partially-superseded — Supersedes ADR 0016. A headless run whose `--transcript` is inside the work tree writes the pre-spawn session record of an orchestrator or reviewer turn to a file outside the tree. `--continue-from` uses it only when it binds to the transcript state, the work tree, and the run, and the ownership check always runs. The mutation check gets no exemption. Decision 2 is superseded by ADR 0030.
- 0028 — [End the Windows process tree of a child when the runtime exits](0028-end-the-windows-process-tree-when-the-runtime-exits.md) — accepted — A synchronous `taskkill /T /F` in the `exit` event ends the tree of each live runtime child on Windows, which execa `cleanup` left alive on `process.exit`. Accepted limit: a hard kill of the runtime runs no handler.
- 0029 — [Refuse --continue-from while a live process holds a Claude session](0029-refuse-continue-from-while-a-live-process-holds-a-claude-session.md) — superseded — `--continue-from` reads the process table once and refuses, before any turn, when another process names the id of a Claude role session. It does not wait for the holder and does not end it. Accepted limits: a holder without the id in its command line, and a fresh run in the same work tree. Superseded by ADR 0031.
- 0030 — [Keep the pre-assigned id of a failed first Copilot turn that saved a turn](0030-keep-the-pre-assigned-id-of-a-failed-first-copilot-turn-that-saved-a-turn.md) — accepted — Partially supersedes ADR 0027 (decision 2). A failed first Copilot turn that reports no id keeps the pre-assigned id, marked `sessionUnconfirmed`, when `events.jsonl` of the session holds a `user.message` event. A failure that saved no turn keeps none. A resume of an unconfirmed id with no saved turn reruns as a first turn.
- 0031 — [Refuse --continue-from and --resume-interrupted while a live process holds a Claude session](0031-refuse-continue-from-and-resume-interrupted-while-a-live-process-holds-a-claude-session.md) — partially-superseded — Supersedes ADR 0029. `--continue-from` and `role dispatch --resume-interrupted` read the process table once and refuse, before any turn, when another process passes the id of a Claude role session through a session flag (`--session-id`, `--resume`, `-r`). Partially superseded by ADR 0032, which replaced the match rule. It does not wait for the holder and does not end it. Accepted limits: a holder without a session flag, and a fresh run in the same work tree.
- 0032 — [Detect a live session holder on interactive init, keep the headless gap](0032-detect-a-live-session-holder-on-interactive-init.md) — accepted — Partially supersedes ADR 0031. A fresh `role dispatch` init reads the Claude session ids of the current and archived state files of the work tree and refuses, before any state change, when a live process passes one through a session flag. The same flag rule now decides the `--continue-from` and `--resume-interrupted` checks. The headless fresh run and a holder without a session flag stay unfound.
- 0033 — [Cancel a run on SIGINT and escalate on a second SIGINT](0033-cancel-a-run-on-sigint-and-escalate-on-a-second-sigint.md) — partially-superseded — A persistent SIGINT listener (`on`, not `once`) lets the first SIGINT abort the run with exit 130 and no re-raise by execa. A second SIGINT force-kills the recorded child trees, writes the transcript or envelope the run holds, and exits 130. It drops the mutation check, the `gate` event, and the state-file writes. Moved from ADR 0029.
- 0034 — [Keep the Codex reviewer descendant gap after a parent end](0034-keep-the-codex-reviewer-descendant-gap-after-a-parent-end.md) — partially-superseded — A command of a Codex `--reviewer-workspace-write` turn can write after its parent ends (issue #712). The runtime now ends the descendant commands of the Codex child at a POSIX parent signal (ADR 0071). The stored-id and `--cd` matches are deferred, and a Windows host cannot test the signal. The reference docs state the operator check for the remaining gaps.
- 0035 — [State that a Copilot worker cannot run shell commands and flag a denied call](0035-state-that-a-copilot-worker-cannot-run-shell-commands-and-flag-a-denied-call.md) — accepted — The Copilot adapter adds no allow flag. The worker contract and the reference docs state that a Copilot worker can be refused a shell call. A turn whose assistant text holds the denial text sets `shellDenied: true` on a worker or reviewer result, envelope, and headless result prompt, and the turn stays ok.
- 0036 — [Bound every snapshot-path read and end the evidence snapshot on a second cancel](0036-bound-every-snapshot-path-read-and-end-the-evidence-snapshot-on-a-second-cancel.md) — accepted — Partially supersedes ADR 0033 (decision 8). Every snapshot-path read has a bound and honors cancel. A second SIGINT ends the evidence snapshot, and the exit waits for the not-captured result.
- 0037 — [State the process rule in child prompts and add no dead-child report](0037-state-the-process-rule-in-child-prompts-and-add-no-dead-child-report.md) — accepted — The worker and reviewer prompts forbid stopping a process the turn did not start and selecting processes by name or command-line match. The runtime adds no dead-child report: a surviving dispatcher already records a child failure, and the next call reports a killed dispatcher as interrupted.
- 0038 — [Run the Codex reviewer with no sandbox by default](0038-run-the-codex-reviewer-with-no-sandbox-by-default.md) — accepted — A Codex reviewer turn runs with `sandbox_mode="danger-full-access"` by default. `--reviewer-sandbox read-only` or `workspace-write` selects a sandbox, and `--reviewer-workspace-write` stays an alias. Partially supersedes ADR 0019.
- 0039 — [Gate full-suite test runs with a machine-wide test slot](0039-machine-wide-test-slot.md) — partially-superseded — `agent-loop test-slot` runs one command through the platform shell only while fewer than its own N slot lock files under `<os tmpdir>/agent-loops/test-slots` are held by live owners, counted under one short lock through `state-lock.mjs`. Default N was `max(1, floor(CPUs / 8))`, now 1 (ADR 0046). The wait bound is 1800 s, the command starts only strictly before it, `--wait 0` is one attempt, and the exit is 75 at the bound. An unreadable slot file counts as held. A signal ends the command tree before the slot is freed, and a nested call runs at once only while its marker names a slot that a live owner holds. Partially superseded by ADR 0046 (decision 3) and ADR 0104 (decision 1, which adds an argument vector beside the one-string form).
- 0040 — [Run the test command in a test slot and route child full suites through the wrapper](0040-run-the-test-command-in-a-test-slot.md) — partially-superseded — Partially supersedes ADR 0017. The runtime runs `--test-cmd` inside a machine-wide test slot through the slot module. The slot wait has its own bound, `AGENT_LOOP_TEST_SLOT_WAIT` or 1800 s, and a wait that reaches it runs no command and reports `slot-timeout`. Worker and reviewer prompts run targeted tests directly and a full suite only through the rendered wrapper command, or rely on CI.
- 0041 — [Declare the run PR after init with `role declare-pr`](0041-declare-the-run-pr-after-init-with-declare-pr.md) — partially-superseded — `agent-loop role declare-pr --pr <n> --parent-session <id>` sets `pr` once on a non-terminal run that has none, for a task whose worker opens the PR. It refuses a run with a PR, a terminal run, `review-only`, a wrong parent session, and a child caller. The run then gets the supplied check status and the declared-PR finish rule. Partially supersedes ADR 0009. Partially superseded by ADR 0043 for the headless loop.
- 0042 — [Remove the reviewer scratch folder in the runtime](0042-remove-the-reviewer-scratch-folder-in-the-runtime.md) — accepted — The runtime creates `.agent-loop/rev/<id>` under the work tree root before each reviewer turn. It names the folder in the prompt. It removes the folder after the post-turn snapshot on every outcome, without following a link. It refuses when a parent is a link. The folder carries its own `.gitignore` with `*`. A failed removal warns.
- 0043 — [Let the headless runtime declare the PR that a worker opens](0043-let-the-headless-runtime-declare-the-pr-a-worker-opens.md) — partially-superseded — Partially supersedes ADR 0041. After a worker turn of a headless run with neither `--pr` nor `--require-ci`, the runtime resolves one open same-repository PR. That PR must match the work tree branch and head. It reads Git and GitHub state only, so no child chooses it. Any other state leaves the run undeclared. The declaration is once and one way. A run with no `--require-ci` then refuses every finish. Partially superseded by ADR 0045 (decision 5).
- 0044 — [Route a targeted run through the test slot while any slot is held](0044-route-a-targeted-run-through-the-test-slot-while-a-slot-is-held.md) — partially-superseded — Partially supersedes ADR 0040 (decision 6). `agent-loop test-slot --if-held` runs a command directly while no slot is held by a live owner, and waits for a slot while any slot is held. Child turns run a targeted test file through it. A targeted run that starts while all slots are free holds no slot. The rule also bars load generators and processes that outlive the turn. A targeted run covers the mirror test files first, then the test files that import a changed source file directly, then the test files of direct importers of a changed file, at most 10 files in total. Partially superseded by ADR 0099 (decision 7).
- 0045 — [Gate the finish of a headless run on the PR that its runtime declares](0045-gate-the-finish-on-the-pr-that-the-headless-runtime-declares.md) — accepted — Partially supersedes ADR 0043 (decision 5). A run whose PR the runtime declared applies the `--require-ci` gate to that PR at finish, so a headless task whose worker opens a PR ends through a reviewer accept with passing required checks. A failing or pending required check refuses the finish. A run with `--pr` and no `--require-ci` still refuses every finish.
- 0046 — [Default the test slot count to one](0046-default-the-test-slot-count-to-one.md) — accepted — Partially supersedes ADR 0039 (decision 3). `agent-loop test-slot` defaults to 1 slot on every CPU count, where it was `max(1, floor(CPUs / 8))`. `--slots` and `AGENT_LOOP_TEST_SLOTS` still override it.
- 0047 — [Give each Codex turn a private temporary directory](0047-give-each-codex-turn-a-private-temporary-directory.md) — partially-superseded — Each Codex turn runs with a private `TMPDIR`, pinned host-state roots, and a removal helper that checks the device and inode.
- 0048 — [Bind the wait-checks states to the PR head commit](0048-bind-the-wait-checks-states-to-the-pr-head-commit.md) — accepted — Partially supersedes ADR 0010 (decisions 2, 8, and 12). `wait-checks` reads each state from the check runs and commit statuses of the PR head SHA, names that commit in `head`, and judges required contexts as the gate does. The required wait refuses an unresolved source. A failure that `gh pr checks` lists settles the wait and is reported in `prFailures`, apart from `checks`. `--head <sha>` waits for the PR head.
- 0049 — [Pin the machine-wide roots for every child turn](0049-pin-the-machine-wide-roots-for-every-child-turn.md) — accepted — `exec` pins the runs root, the test-slot directory, and the session-record directory for every worker and reviewer spawn, and sets `npm_config_logs_max=0` so npm writes no debug log. Partially supersedes ADR 0047.
- 0050 — [Let an operator add ignored paths to the local-file copy](0050-let-an-operator-add-ignored-paths-to-the-local-file-copy.md) — accepted — `--copy-local-path` adds ignored paths to the copy of a role run, refused before any state or child when tracked, linked, unignored, or unsafe. Partially supersedes ADR 0018.
- 0051 — [Record a verified PR-head compare without the required-check gate](0051-record-a-verified-pr-head-compare-without-the-required-check-gate.md) — partially-superseded — `role finish --compare-head <pr>` verifies the PR head and the clean reviewed tree, reads no required-check source, and records `headCompare: "verified"`, distinct from `unresolvedCompare`. Partially superseded by ADR 0052 (decision 5, interactive only).
- 0052 — [Verify the PR head in a headless run without the required-check gate](0052-verify-the-pr-head-in-a-headless-run-without-the-required-check-gate.md) — partially-superseded — `agent-loop --compare-head <pr>` applies the ADR 0051 compare at finish, emits a `head-compare` event, and exits 0, distinct from `unresolvedCompare`. Refused with `--pr`, `--require-ci`, and `review-only`. Partially supersedes ADR 0051.
- 0053 — [Compare the head of a worker-opened PR that the runtime refused to declare](0053-compare-the-head-of-a-worker-opened-pr-that-the-runtime-refused-to-declare.md) — accepted — The runtime records a worker-opened PR that it refused to declare as `pr-undeclared` and applies the ADR 0052 head compare to it at finish, with no operator choice. A continuation does not restore it. Partially supersedes ADR 0052.
- 0058 — [Remove the turn directory of a dispatch that died mid-turn](0058-remove-the-turn-directory-of-a-dispatch-that-died-mid-turn.md) — partially-superseded — A role dispatch records its Codex turn directory and child in `lastDispatch.turnTmpdir`, and the call that marks the dead run `interrupted` removes the directory with the ADR 0047 identity checks, unless a process of the turn may still run. Extends ADR 0047. ADR 0063 adds the process group and record origin checks.
- 0063 — [Close the limits of the abandoned turn directory removal that the process group and the record origin cover](0063-close-the-limits-of-the-abandoned-turn-directory-removal-that-the-process-group-and-the-record-origin-cover.md) — accepted — A POSIX call keeps an abandoned turn directory while the process group of the dead child has a live member, refuses a record outside the inherited temporary directory, and clears a stale record after a failed record write. The unrecorded child stays. Partially supersedes ADR 0058.
- 0068 — [Give the turn of every adapter a private temporary directory](0068-give-the-turn-of-every-adapter-a-private-temporary-directory.md) — partially-superseded — A Claude Code, agy, Copilot, or opencode turn runs with `TMPDIR`, `TEMP`, and `TMP` set to a private `al-` directory that the runtime removes, as a Codex turn does. Decisions 1 to 3 hold, and ADR 0069 supersedes decision 4. Partially supersedes ADR 0047. ADR 0095 lists every entry of the one post-turn read, with no settle re-read, so the all-entries rule that ADR 0069 restated holds.
- 0069 — [Mark the turn directories that any agent-loop process registered](0069-mark-the-turn-directories-that-any-agent-loop-process-registered.md) — partially-superseded — `inheritedTmpdirEntries` lists every entry that the post-turn read holds and prefixes the `al-` turn directory that an agent-loop process on the host registered in the runs root with `registered/`, while the entry still has the registered device and inode. A turn cannot hide a still-existing entry by a record. Partially supersedes ADR 0068 (decision 4). Partially superseded by ADR 0076 (decision 2), which ADR 0095 supersedes; ADR 0095 restores decision 2 for the one post-turn read and supersedes decision 3's `open` rule.
- 0070 — [Replace the model of a role that has completed no turn](0070-replace-the-model-of-a-role-that-has-completed-no-turn.md) — partially-superseded — `role set-model` replaces the model of one role with no `ok` turn on an `active` run, behind the stored `--parent-session` id, and records `modelChanges`. No model is probed at init. Partially superseded by ADR 0084, which recognizes a Codex model refusal and refunds the first turn of the role.
- 0071 — [End the Codex reviewer command tree on POSIX after a parent signal](0071-end-the-codex-reviewer-command-tree-on-posix-after-a-parent-signal.md) — accepted — A POSIX parent signal ends the descendant commands of a Codex reviewer child, by a bounded process-table walk with a start-stamp check. Partially supersedes ADR 0034 decisions 1, 2, and 5.
- 0072 — [Keep the orchestrator command tree gap after a headless parent SIGKILL](0072-keep-the-orchestrator-command-tree-gap-after-a-headless-parent-sigkill.md) — accepted — A `SIGKILL` of a headless parent runs no handler. An orchestrator command tree can write to the work tree after the parent ends (issue #1333). The gap stays, and the operator check of ADR 0034 covers an orchestrator turn.
- 0073 — [Lock the work tree of an active run](0073-lock-the-work-tree-of-an-active-run.md) — accepted — `role dispatch` takes a Git work tree lock at init for a linked `--cwd`, with the reason `agent-loop run <id> active`. A terminal `finished`, `aborted`, or `halted` unlocks it. The main work tree takes no lock, an existing lock of another owner is kept, and every lock failure only warns.
- 0074 — [Report the side that changed in localFilesDiffer](0074-report-the-side-that-changed-in-local-files-differ.md) — partially-superseded — The init stores one SHA-256 per copied local file. A later dispatch reports `localFilesDiffer` as `{path, changed}` with `source`, `copy`, or `both`, and fails closed as `unknown` when it cannot prove the side. Partially superseded by ADR 0075 (decision 5's unconditional source action) and ADR 0078 (decision 2 and decision 3's init-hash comparisons, and decision 5's source action).
- 0075 — [Report a copied source that changed inside a turn window](0075-report-a-copied-source-that-changed-inside-a-turn-window.md) — accepted — Each worker and reviewer turn hashes every copied source before and after it, and names a source that changed inside the window as `localSourceChangedInTurn`, by path only. The parent reports it under `open` and asks the user before a refresh. Partially supersedes ADR 0074 (decision 5's unconditional source action).
- 0076 — [Leave out an inherited temporary directory entry that the settle re-read no longer holds](0076-leave-out-an-inherited-tmpdir-entry-that-the-settle-re-read-no-longer-holds.md) — superseded — `inheritedTmpdirEntries` read the inherited temporary directory again after a short settle and kept only the names that the second read still held. Partially superseded ADR 0069 (decision 2) and qualified ADR 0068's all-entries rule. Superseded by ADR 0081 and ADR 0095, which lists the entries of the one post-turn read with no settle and no `open` rule.
- 0078 — [Record a hand refresh of a copied local file](0078-record-a-hand-refresh-of-a-copied-local-file.md) — accepted — `role refresh-local --path <path>` records one refresh. It writes the source bytes over the run copy and stores the new hash for that path only. It runs behind the stored parent session id, the child guard, and the non-terminal guard.
